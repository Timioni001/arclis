# Brand assets

| File | What it is |
|---|---|
| `mark.svg` | Arclis's own mark. Source of truth for the favicons and `social-card.png`, both generated by `scripts/make-icons.py`. |
| `social-card.png` | The `og:image` link preview card, 1200x630. Generated. |
| `meteora.png` | Meteora's mark, supplied by the project owner. |
| `clawpump.png` | Clawpump's mark, supplied by the project owner. |

## The third-party marks

`meteora.png` and `clawpump.png` are the trademarks of their respective
owners. They appear here for one purpose: naming, in a "Built on" credit and
in a stat tile, software this project actually uses. Nothing here implies
endorsement, affiliation or sponsorship, and the registry deliberately does
not show them beside venue names - see the comment on the stat tile in
`src/screens/Markets.tsx`.

They were supplied as 1254x1254 artwork on a flat background, one white and
one near-black, and prepared with:

```
python3 scripts/prepare-brand-assets.py <supplied.png> app/public/brand/<id>.png
```

That knocks the background out by flood-filling inwards from the border only,
crops to what remains and downsamples premultiplied. Dropping a supplied file
straight in instead would put a hard white or black square on the lime hero;
a global colour key instead of a border fill would punch holes through the
white glints inside Clawpump's claw.

## Adding another

Prepare the file as above, then add an entry to `ECOSYSTEM` in
`src/components/ui/Brand.tsx` with `asset: "<id>.png"`. A brand with neither
`asset` nor a drawn `mark` renders a monogram in the interface's own type,
which is the honest fallback when no real artwork is available.
